# 記法仕様・規約（NOTATION）

このファイルは「中間記法(MNP)の入力ルール・規約」を定義する。
人間が読む仕様書であると同時に、Claude Code が `data/diagram.mnp` を編集する際に従うルール（=システムプロンプト相当）でもある。
ドメインを差し替えるときは `domain/schema.js` とこのファイルをセットで書き換える。

## このドメイン

サービスエコシステム：複数のアクター（ノード）と価値交換の矢印で、サービスがどう成り立つかを可視化する。
良い図の条件：価値の流れが双方向に描かれている／ノードが重ならない／矢印が交差しすぎない。

## 記法リファレンス

```
actor ID "名前" 色 アイコン
  role: 役割説明
  memo: 自由メモ
ID1 -> ID2 "価値・サービス名"    実線: 主要な価値交換
ID1 --> ID2 "価値・サービス名"   点線: 副次的な交換
layout
ID x y
```

- 色: teal amber coral violet emerald purple pink sky orange lime
- アイコン: person group company store ai app platform data gov service

## 設計ルール（編集時に厳守）

1. 記法は常に「全要素・全関係・全layout座標を含む完全な状態」を保つ。部分断片で上書きしない。
2. 既存要素の座標は現状のまま維持する。新要素は既存ノードの近傍（±200px程度）の空きに置く。
3. ID は英数字のみ。スペース・日本語は使わない。既存 ID は変更しない。
4. 同一の src→dst 間の矢印は1本のみ。双方向にしたい場合は向きの違う2本にする。
5. 図の変更を伴わない説明・質問だけのときは記法を書き換えない。

## ドメインを変えるときの手順

1. `domain/schema.js` の `title` / `nodeKeyword` / `attributes` / `palette` / `icons` / `edge` を書き換える。
2. このファイルの「このドメイン」「記法リファレンス」「設計ルール」を新ドメインに合わせて書き直す。
3. `data/diagram.mnp` を新しい記法で初期化する。
4. グラフ（ノード＋矢印）で表現できる題材なら JavaScript の変更は不要。
